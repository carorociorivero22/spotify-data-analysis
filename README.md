Análisis de Datos de Spotify
Descripción

Proyecto personal de análisis de datos sobre Spotify, realizado como mi primer proyecto individual de portfolio.

El objetivo del proyecto es analizar qué características tienen las canciones más exitosas y qué factores se relacionan con su cantidad de reproducciones y popularidad.

Datos

El conjunto de datos está compuesto por:

2.007 canciones
274 artistas
20 géneros musicales
30 países
Período de lanzamiento: 2020–2025
Más de 272 millones de reproducciones
Herramientas utilizadas
MySQL — almacenamiento, consultas y análisis de datos.
SQL — limpieza, validación y creación de consultas y vistas analíticas.
Power BI — visualización y desarrollo del dashboard.
Análisis realizado

El proyecto analiza diferentes dimensiones del catálogo:

Reproducciones y popularidad.
Géneros musicales.
Artistas.
Países.
Evolución temporal.
Características musicales de las canciones.
Comparación entre las canciones con mayor cantidad de reproducciones y el resto del catálogo.
Dashboard

El dashboard fue desarrollado en Power BI y está organizado en tres páginas:

Resumen general
Géneros y países
Comportamiento temporal

El informe completo, incluyendo el análisis y las páginas del dashboard, se encuentra disponible en el PDF del repositorio.
